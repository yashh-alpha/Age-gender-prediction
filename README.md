# Age and Gender Prediction using MobileNetV2

## Overview

This project is a Deep Learning application that predicts a person's **age** and **gender** from a facial image using a **Multi-Output Convolutional Neural Network** built with TensorFlow and MobileNetV2.

The model uses **Transfer Learning** with a pretrained MobileNetV2 backbone and simultaneously performs:

* **Age Prediction** (Regression)
* **Gender Classification** (Binary Classification)

A Streamlit web application is provided for interactive predictions.

---

## Features

* Transfer Learning using MobileNetV2
* Multi-output neural network
* Age prediction from facial images
* Gender classification from facial images
* Streamlit web application
* Trained on the UTKFace dataset
* End-to-end machine learning pipeline

---

## Dataset

### UTKFace Dataset

The UTKFace dataset contains over 20,000 face images with labels encoded in the filename.

Example:

25_1_0_20170116174525125.jpg

Where:

* 25 → Age
* 1 → Gender (Female)
* 0 → Ethnicity

Gender Encoding:

* 0 = Male
* 1 = Female

Dataset Link:

https://susanqq.github.io/UTKFace/

## Model Architecture

Input Image (224×224×3)
↓
MobileNetV2 (Pretrained)
↓
GlobalAveragePooling2D
↓
Dense(128, ReLU)
↓
Dropout(0.3)
↓
├── Age Head → Dense(1)
└── Gender Head → Dense(1, Sigmoid)

### Loss Functions

Age Prediction:

* Mean Absolute Error (MAE)

Gender Classification:

* Binary Crossentropy

Optimizer:

* Adam

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/Age-gender-prediction.git

cd Age-gender-prediction
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate the environment:

### Windows

```bash
venv\Scripts\activate
```

### Linux / Mac

```bash
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## Training

Run:

```bash
python src/train.py
```

The trained model will be saved inside:

```text
models/
```

---

## Running the Streamlit App

```bash
streamlit run app/app.py
```
